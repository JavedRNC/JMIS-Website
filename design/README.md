# Design prototype

A faithful static clone of the homepage design (layout + motion modelled on iqraschool.com — white ground, teal accent,
Ubuntu/Karla type), with placeholder content. No build step: this is the visual reference that the Next.js frontend
(reading the backend API) will be built from.

**Run it locally:** just open `index.html` in a browser (double-click), or:
```
cd design && python -m http.server 8080   # then open http://localhost:8080
```
Photos are placeholders — real logo and images come from the admin panel in the live build.
